# BRIEF — mercurius-i18n

Тексты агента на нескольких языках за небольшим интерфейсом `Translator`: плоские PHP-каталоги «ключ → текст» с
именованными подстановками, формы множественного числа и проверка, что языки совпадают по ключам и подстановкам. Здесь
лежат все тексты, которые агент пишет сам, на русском (по умолчанию) и английском, поэтому язык агента — одна
настройка. Пакет — часть Меркурия (`opencck/mercurius`), подключается сабмодулем в `packages/i18n/` и не зависит от
приложения; кроме PHP 8.2 и `ext-mbstring`, зависимостей нет.

## Назначение и границы

В пакете:

- интерфейс `Translator` и реализация по каталогам;
- каталоги `lang/ru.php` и `lang/en.php`: ответы команд, карточки, статусы запуска, сообщения владельцу, описания и
  результаты инструментов, системный промпт и служебные рамки, тексты тем `self_info` (`self.<тема>`);
- переводчик процесса (`Lang`) и функции `t()`, `tp()`;
- правила форм числа для русского и английского;
- проверка совпадения каталогов.

В приложении остаётся:

- выбор языка: настройка `AGENT_LANGUAGE` (`ru` или `en`), переводчик ставится при старте после наложения настроек;
- тест, что каждый ключ из кода приложения есть в каталоге;
- то, что не переводится: журналы (на английском), ответы модели, русские стоп-слова и основы для поиска по памяти,
  образцы для поиска секретов и подмены инструкций, внутренние коды.

## Устройство

| Класс / каталог | Что делает |
|-----------------|------------|
| `Translator` | `t(key, params)`, `plural(key, count, params)`, `language()`, `languages()` |
| `CatalogTranslator` | Переводчик по каталогам «язык → ключ → текст»; первый каталог — язык по умолчанию; неизвестный язык — язык по умолчанию; нет текста — текст языка по умолчанию, затем сам ключ; подстановка без значения остаётся как есть |
| `Catalogs` | `LANGUAGES` (`ru`, `en`, по умолчанию первый); `bundled()` — встроенные каталоги из `lang/`; `shape()` — ключи с подстановками для проверки совпадения (формы числа считаются одним ключом, `%s`/`%d` — по порядку) |
| `Plural` | `form(language, count)`: в русском `one`, `few`, `many`, в английском и других — `one`, `other`; `forms(language)` |
| `Lang` | Переводчик процесса: `use()`, `current()` (пока не задан — русский по встроенным каталогам), `reset()` для тестов |
| `functions.php` | `t(key, params)` и `tp(key, count, params)` через `Lang::current()` |
| `lang/ru.php`, `lang/en.php` | Каталоги: плоские массивы, ключ — `область.имя`, подстановки `{name}`, формы числа — `ключ.one`, `ключ.few`… |

## Решения

- **Тексты агента — вне кода приложения:** язык меняется одной настройкой, перевод правится в одном месте.
- **Образец — `agent/i18n.py` hermes:** плоские ключи с точками, именованные подстановки, откат на язык по умолчанию,
  затем на ключ, проверка одинакового набора ключей; ссылка `ref:` — в `CatalogTranslator`.
- **Отличия от hermes:** каталоги — PHP-массивы без YAML и кешей; язык по умолчанию — русский, а не английский;
  русские формы числа `one`, `few`, `many`.
- **Доступ через функцию `t()` с переводчиком процесса,** а не через конструкторы: тексты стоят в сотнях мест, и
  протаскивать переводчик в каждый конструктор нецелесообразно.
- **Русский по умолчанию до вызова `Lang::use()`:** существующие проверки текстов в тестах не меняются.
- **Совпадение каталогов — условие `composer check`:** у всех языков одинаковые ключи и подстановки, у ключа с числом —
  все формы своего языка; порядок `%s`/`%d` сравнивается, потому что `sprintf()` ломается, если перевод его меняет.
- **Отсутствующий текст не роняет агента:** вместо исключения — текст языка по умолчанию или сам ключ.

## Проверки

- `composer check` — PHPUnit (`CatalogsTest`, `TranslatorTest`), PHPStan (уровень `max`), Psalm (`errorLevel="1"`);
  группы `integration` в пакете нет.
- CI (`.github/workflows/ci.yml`): одна задача, PHP 8.2 (другая версия — вручную через `workflow_dispatch`), push и
  pull request в `master`, изменения только в `*.md` не запускают, `cancel-in-progress`, кеш Composer и анализаторов,
  10 минут; без сети и секретов.
